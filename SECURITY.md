# Security

Report vulnerabilities privately through GitHub: the **Security** tab of this repo, then **Report a vulnerability**. Please don't open a public issue for anything that could be abused.

Useful things to include: the version or commit, what you did, what you expected and what happened, and whether it needs a particular config (`config.yml` values, a Paper version, WorldGuard).

Scuttle is a hobby project run by one person, so replies are best effort. Anything that gets a model past the tool allowlist, the spend and rate caps, or the kill switch is taken seriously, because those are what keep a server of kids safe.

Only the latest release and `main` get fixes.

Never put an API key, RCON password or panel token in an issue, a PR or a log you attach. If you leaked one, rotate it first.
